# Wintersweater

縦書きに対応したシンプルな小説執筆エディタ。

Wintersweaterは、日本語の縦書き執筆に特化したデスクトップ向け小説エディタです。

## 機能

- 日本語の縦書き表示・編集
- 複数ページ編集
- 原稿レイアウトのカスタマイズ
- 文字数カウント
- 検索・置換
- 自動保存
- ドキュメント管理
- ゴミ箱機能（復元および完全削除に対応）
- 原稿設定のインポート・エクスポート

## 技術スタック

| コンポーネント | 技術 |
|---|---|
| バックエンド | Python 3.12 / FastAPI |
| データベース | SQLite |
| フロントエンド | HTML / CSS / JavaScript |
| デスクトップアプリケーション | Tauri v2 |
| ネイティブ層 | Rust |
| 開発環境 | Docker Compose |

## 動作環境・要件

- Ubuntuを搭載したWSL2（現在の開発環境）
- DockerおよびDocker Compose
- Rustツールチェーン
- Tauri CLI
- Python 3.12（ローカルでのAPI開発時に必要となる場合があります）

## 始め方

### 1. APIサーバーの起動

プロジェクトのルートディレクトリで、以下のコマンドを実行します。

```bash
docker compose up -d --build
```

APIサーバーおよびWebアプリケーションは、以下のURLから利用可能です。

http://localhost:8000

### 2. デスクトップアプリケーションの起動

APIサーバーが起動している状態で、別のターミナルを開き、以下のコマンドを実行します。

```bash
cargo tauri dev
```

これでWintersweaterデスクトップアプリケーションが起動します。

開発中は、APIサーバーとTauriアプリケーションをそれぞれ個別に起動する必要があります。

## アプリケーションの停止

### APIサーバーの停止

```bash
docker compose down
```

### APIサーバーのログ確認

```bash
docker compose logs -f wintersweater
```

### デスクトップアプリケーションの停止

Tauriのウィンドウを閉じるか、アプリケーションを起動したターミナルで `Ctrl+C` を押してください。

## データ保存

SQLiteデータベースファイルは `data/` ディレクトリ内に保存されます。

データベースには原稿データが含まれています。データベースファイルや `data/` ディレクトリをGitにコミットしないように注意してください。メンテナンスの実行やアプリケーションデータの削除を行う前に、必ずデータベースのバックアップを取ってください。

## 原稿設定

原稿のレイアウト設定は、JSONファイルとしてエクスポートしたり、JSONファイルからインポートしたりすることができます。

設定項目は以下の通りです。

- 用紙サイズ
- 1行あたりの文字数
- 1ページあたりの行数
- フォントサイズ
- ページ余白
- ページ番号

### エクスポート

現在の原稿設定をJSONファイルとしてエクスポートします。

### インポート

あらかじめエクスポートしておいたJSONファイルを読み込み、その設定を適用します。

**注:** 原稿の本文は設定ファイルには含まれません。
