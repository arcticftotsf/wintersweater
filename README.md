# Wintersweater

日本語の縦書き執筆に特化した、シンプルな小説執筆エディタです。

原稿用紙に近いレイアウトで、複数ページにわたる文章を縦書きで執筆できます。

## 主な機能

- 日本語の縦書き表示・編集
- 複数ページ編集
- 原稿レイアウトのカスタマイズ
- 文字数カウント
- 検索・置換
- 自動保存
- ドキュメント管理
- ゴミ箱機能（復元・完全削除）
- 原稿設定のインポート・エクスポート

## 動作環境

- Windows 10 / 11
- 64bit（x64）

## ダウンロード・インストール

[GitHub Releases](https://github.com/arcticftotsf/wintersweater/releases) から最新版のインストーラーをダウンロードしてください。

1. インストーラー（`.exe`）を実行します。
2. 画面の案内に従ってインストールします。
3. Wintersweaterを起動します。

初回起動時にWindowsのセキュリティ警告が表示される場合があります。

## データ保存

原稿データはSQLiteデータベースに保存されます。

Windowsでは、以下の場所に保存されます。

`%APPDATA%\Wintersweater\wintersweater.db`

原稿データを失わないよう、必要に応じてデータベースファイルをバックアップしてください。
